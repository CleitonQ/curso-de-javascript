# curso-de-javascript
curso-de-javascript

Os comandos HTML mais usados incluem tags para estruturação de conteúdo (como <header>, <footer>, <main>), formatação de texto (como <strong>, <em>, <mark>), links e navegação (<a>, <nav>), formulários (<form>, <input>, <label>), e elementos multimídia (<img>, ` 


Seletores:
Seletor de Elemento:
Aplica estilos a todos os elementos de um determinado tipo (ex: p para todos os parágrafos).
Seletor de Classe:
Aplica estilos a elementos com uma classe específica (ex: .destaque para elementos com a classe "destaque").
Seletor de ID:
Aplica estilos a um único elemento com um ID específico (ex: #cabecalho para o elemento com o ID "cabecalho").
Seletor de Atributo:
Aplica estilos a elementos com base em seus atributos (ex: img[src] para imagens com um atributo 'src'). 
Propriedades de Estilo:
Cores: color (cor do texto), background-color (cor de fundo). 
Fontes: font-family (família da fonte), font-size (tamanho da fonte), font-weight (espessura da fonte). 
Margens e Preenchimentos: margin (margem), padding (preenchimento), margin-top, margin-right, margin-bottom, margin-left, padding-top, padding-right, padding-bottom, padding-left. 
Posicionamento: position (posição), top, right, bottom, left (para posicionamento absoluto ou relativo). 
Bordas: border (largura, estilo e cor da borda), border-radius (arredondamento das bordas). 
Texto: text-align (alinhamento do texto), text-decoration (decoração do texto), text-transform (transformação do texto). 
Largura e Altura: width (largura), height (altura). 
Exibição: display (como o elemento é exibido, ex: block, inline, none). 
Flutuação: float (faz um elemento flutuar à esquerda ou à direita). 
Opacidade: opacity (transparência do elemento).
